# MovieLens Item-based Collaborative Filtering

Рекомендательная модель на основе схожести фильмов, обученная на полном датасете MovieLens `ml-latest` (33.8 млн оценок). Сравнивается с бейзлайном по RMSE.

## Данные

[MovieLens Latest Full](https://grouplens.org/datasets/movielens/latest/), файл `ratings.csv` (`userId, movieId, rating, timestamp`). Распакованный архив нужно положить в `data/ml-latest/`.

Разбиение train/test 80/20 (`seed=42`): 27.07 млн оценок в train и 6.77 млн в test.

## Модель

1. **Бейзлайн:** всем парам предсказывается глобальный средний рейтинг по train (3.54).
2. **Схожесть фильмов:** корреляция Пирсона по оценкам общих пользователей. Учитываются фильмы с ≥100 оценками и пары с ≥10 общими пользователями; пары с |r| ≤ 0.1 отбрасываются.
3. **Предсказание** для пары (пользователь, фильм) по 15 самым похожим фильмам, которые пользователь уже оценил:
   - вес соседа: `|r| · min(1, common_users / 25)`, то есть корреляция по малому числу общих пользователей учитывается слабее;
   - при отрицательной корреляции оценка отражается: `6 − rating`;
   - итог: `0.8 · взвешенное среднее соседей + 0.2 · средний рейтинг фильма`, обрезанный до `[0.5, 5]`;
   - если подходящих соседей меньше двух, используется средний рейтинг фильма.
4. Словари средних рейтингов, схожестей и профилей пользователей рассылаются на executors через **broadcast**, предсказание считается в UDF.

### Компромиссы ради времени расчёта

Попарная схожесть растёт квадратично, поэтому модель строится для 500 популярных фильмов, профили пользователей собираются по 20% выборке train, а RMSE считается на 10% выборке test. Все параметры вынесены в аргументы скрипта.

## Запуск

```bash
python src/item_cf.py --ratings data/ml-latest/ratings.csv \
    --max-movies 500 --neighbours 15 --user-sample 0.2 --test-sample 0.1
```

Исследование по шагам лежит в [notebook.ipynb](notebook.ipynb).

## Результаты

| Модель | RMSE |
|---|---|
| Глобальный средний рейтинг (бейзлайн) | 1.0640 |
| **Item-based CF** | **0.9667** |

RMSE снизился на **9.14%** относительно бейзлайна.

## Что можно улучшить

- Схожесть через Spark (self-join по `userId`) вместо сбора на драйвер, чтобы покрыть все фильмы.
- Учитывать смещения пользователя и фильма (baseline predictors) в формуле предсказания.
- Сравнить с ALS из `pyspark.ml.recommendation`.
