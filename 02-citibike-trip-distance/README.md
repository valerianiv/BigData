# Citi Bike Trip Distance

Расчёт длины каждой поездки нью-йоркского байкшеринга Citi Bike по координатам станций и описательная статистика по дистанциям.

## Данные

[Citi Bike System Data](https://citibikenyc.com/system-data), файл `201902-citibike-tripdata.csv` (февраль 2019) из [S3-бакета](https://s3.amazonaws.com/tripdata/index.html). Файл нужно положить в `data/`.

## Как устроен расчёт

- Расстояние считается по **формуле гаверсинусов** (кратчайший путь по поверхности сферы, R = 6371 км).
- Формула собрана из встроенных функций Spark SQL (`sin`, `cos`, `asin`, `sqrt`), без Python UDF. Поэтому вычисление идёт в JVM, данные не сериализуются в Python, и Catalyst может оптимизировать план.
- Значение под корнем ограничено отрезком `[0, 1]`, чтобы погрешность вычислений с плавающей точкой не дала `NaN` в `asin`.
- Строки без координат и поездки, которые начались и закончились на одной станции, отбрасываются.
- Медиана считается через `approxQuantile` с относительной погрешностью 1%, без полной сортировки.

## Запуск

```bash
python src/trip_distance.py --input data/201902-citibike-tripdata.csv
# опционально: сохранить поездки с дистанцией в parquet
python src/trip_distance.py --output output/trips_with_distance
```

Исследование лежит в [notebook.ipynb](notebook.ipynb).

## Результаты

| Метрика | Значение |
|---|---|
| Максимум | 15 326 м |
| Среднее | 1 640 м |
| Медиана | 1 259 м |
| Стандартное отклонение | 1 289 м |

Среднее больше медианы, а разброс большой: у распределения длинный правый хвост. Большинство поездок короткие, по своему району, но встречаются и поездки через весь город.
